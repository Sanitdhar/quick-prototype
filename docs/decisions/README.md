# Decisions

Lightweight architecture decision records (ADRs) for choices worth remembering the
reasoning behind — not every choice, just the ones a future reader (including you)
would otherwise have to reverse-engineer from a diff.

One file per decision, named `NNNN-slug.md` (zero-padded, sequential — e.g.
`0001-shared-uv-venv.md`), using [`_template.md`](./_template.md). Once written, a
decision record is not edited to reflect new context — write a new one that
supersedes it and link back, so the history of _why_ stays intact.
